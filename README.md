# WWT&A

На хакатоне ответы организаторов разбросаны по разным местам: часть в чатах, часть в топиках форума, часть звучит только на онлайн-сессиях. Здесь лежат методы и код, которыми наша команда (МИСИС) собирала их в один текстовый источник для людей и ИИ-агентов. Впервые пайплайн обкатали на О!Хакатоне 2026 (октябрь, трек Островка).

```
Telegram-чаты и топики ──fetch.py──► qa/raw/<источник>.md       (сообщения организаторов помечены [ОРГ])
Записи онлайн-сессий  ──transcribe.py──► qa/transcripts/<запись>.md  (таймкоды)
                                  │
                                  ▼
                 агент или человек читает сырьё
                                  │
                                  ▼
       Q&A.md: вопрос → ответ → ссылка на сообщение → что это меняет у нас
       Вопросы организаторам.md: что спросить, зачем, статус
```

## Что внутри

| Путь | Что делает |
|---|---|
| [`tg_qa/login.py`](tg_qa/login.py) | Одноразовый вход в Telegram под своим аккаунтом (Telethon): по QR или по коду |
| [`tg_qa/fetch.py`](tg_qa/fetch.py) | Выгрузка выбранных чатов и топиков в markdown. Только чтение, догрузка инкрементальная, сообщения админов помечаются `[ОРГ]` |
| [`transcribe/transcribe.py`](transcribe/transcribe.py) | Расшифровка записей (mp3/mp4/…) через faster-whisper `large-v3-turbo`: на GPU, а без CUDA на CPU |
| [`templates/`](templates/) | Шаблоны `Q&A.md` и `Вопросы организаторам.md` |
| [`docs/`](docs/) | Методы: почему всё устроено именно так и на что мы напоролись |

## Быстрый старт

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt     # Linux/macOS: .venv/bin/pip
```

**Telegram**

1. Скопировать `tg_qa/.env.example` в `tg_qa/.env` и вписать `TG_API_ID` и `TG_API_HASH` с <https://my.telegram.org> (раздел API development tools).
2. Войти один раз: `python tg_qa/login.py`. QR сканируется в Telegram на телефоне: Настройки → Устройства → Подключить устройство.
3. Найти чаты: `python tg_qa/fetch.py --list` (по умолчанию ищет «хакат» и «hack» в названии, свои слова задаются в `--keywords`).
4. Скопировать `tg_qa/sources.example.json` в `tg_qa/sources.json` и вписать нужные чаты и топики.
5. Выгружать: `python tg_qa/fetch.py --since 2026-07-01`. Повторный запуск дописывает только новые сообщения.

**Записи**

```bash
python transcribe/transcribe.py media/              # все новые файлы папки
python transcribe/transcribe.py media/qa.mp4        # один файл
```

По умолчанию всё ложится в `qa/` в корне репо, другой каталог задаётся через `--out`. Каталоги `qa/` и `media/` стоят в `.gitignore`: в них чужая переписка и чужие голоса.
